3.4 百度云

云计算 · 典型云计算平台 — 背景与核心技术 / 三大服务 / 行业应用（复习卡片）

一句话定位：百度云不是"纯资源型 IaaS"，而是以 AI 原生 为差异点的"云智一体"平台，核心技术可概括为 ABC 战略（A 人工智能 + B 大数据 + C 云计算）。

一、背景与核心技术

1. 背景

  • 百度以搜索引擎起家，长期沉淀海量数据处理、分布式系统、机器学习工程能力，这是它做云的独特基因。
  • 2015 年前后开放自有技术能力，整合为 百度智能云；差异化打法是把 AI 能力作为云的原生能力输出，即"云智一体"。
  • 战略口号常概括为 ABC 战略：A（AI）+ B（Big Data）+ C（Cloud）三者一体，向下依赖自建基础设施，向上输出智能服务。

二、三大服务：智能云 / 网盘 / AI 开放平台

三个"百度云"容易混淆，关键看定位、能力、用户：

服务定位典型能力 / 产品主要用户
百度智能云 企业级云计算平台
(IaaS/PaaS/SaaS + AI)		 云服务器 BCC、对象存储 BOS、数据库 RDS、大数据、AI 平台（AI Studio / EasyDL / BML）、行业解决方案 企业、政府、开发者
百度网盘 个人云存储服务 文件同步备份、在线预览、共享链接、相册 / 文档管理 个人消费者
百度 AI 开放平台 AI 能力开放（API/SDK） 语音识别/合成、OCR 文字识别、人脸识别、NLP、图像识别、UNIT 对话、EasyDL 零代码定制 开发者、企业集成
区分口诀：智能云 = to B 的"全家桶"云平台；网盘 = to C 的"网盘/U盘"；AI 开放平台 = 把"百度大脑"当接口对外调用的"能力超市"。

三、百度云在各行业的应用

差异化在于"AI 原生"，落地场景普遍带明显的智能化特征：

金融
智能风控、智能客服、反欺诈、智能营销
医疗健康
灵医智惠、医学影像 AI 辅助诊断、辅助诊疗
智能制造
工业视觉质检、设备预测性维护、工业互联网
智能交通 / 自动驾驶
Apollo 自动驾驶、智能信控、车路协同（代表赛道）
政务民生

媒体文旅

农业

核心考点速记（对应考纲三问）

  1. 背景与核心技术：抓住"云智一体 / ABC 战略"主线；四个名字——百度大脑、飞桨、昆仑芯片、分布式存储与计算，外加云原生（K8s/容器）。
  2. 三大服务（最易混）：百度智能云 → to B 企业云平台；百度网盘 → to C 个人云存储；百度 AI 开放平台 → 以 API/SDK 对外开放 AI 能力。
  3. 行业应用：高频考点——金融智能风控、医疗影像 AI、智能制造质检、Apollo 自动驾驶 / 智能交通，最能体现"AI 原生云"差异化。

关联 3.5 平台选择 相比 AWS/Google 的通用算力、华为云的政企与 ICT，百度云的突出优势在 AI 能力、中文 NLP/OCR、自动驾驶 场景。
