5.4容灾备份

1两个核心指标（先背这个）

RTO（Recovery Time Objective，恢复时间目标）：从灾难发生到业务系统恢复可用所允许的最长时间。RTO 越小，恢复越快、要求越高。
RPO（Recovery Point Objective，恢复点目标）：灾难发生时，允许丢失的数据量所对应的时间点（最多丢多久的数据）。RPO 越接近 0，数据越完整、要求越高。

一句话记：RTO 管"停多久"，RPO 管"丢多少"；两个值都是越小越贵、要求越高。

时间轴上：RPO 是"最后一次成功复制"到"灾难发生"之间允许丢失的数据窗口；RTO 是"灾难发生"到"业务恢复"的中断时长。

2等级标准：国标 GB/T 20988-2007

《信息系统灾难恢复规范》将容灾分为 6 级，保护能力逐级增强、RTO 逐级缩短：

等级名称关键特征RTO / RPO 水平
第1级基本支持数据备份介质异地存放，无备用场地/设备RTO 天~周
第2级备用场地支持预先准备好备用场地RTO 数天
第3级电子传输·部分设备数据电子传输到异地，配部分备用设备RTO 天级
第4级电子传输·完整设备异地有完整备用系统，定时批量传输RTO 天~小时
第5级实时传输·完整设备数据实时复制到异地，远程完整设备RTO 小时级
第6级零丢失·远程集群远程双活/集群，灾难时实时切换RPO≈0、RTO 秒/分级
横条越长 = 保护能力越强；RTO 随等级升高而缩短，L6 达到 RPO≈0。

3容灾备份的关键技术

围绕"把数据安全地复制到别处、并能快速拉起来"，核心技术有四类：

① 数据复制（Data Replication）

  • 同步复制：写入须主、备两端都确认才返回。RPO≈0，但受网络延迟限制，通常只适合 ≤100 km 的同城场景。
  • 异步复制：先写本地、再批量/实时传异地。RPO 会有少量丢失，但可支持远距离、跨地域。
  • 折中：半同步 / 组复制等。

② 快照（Snapshot）

对某一时刻数据的"照片"，用于本地快速恢复、回滚到干净状态。底层常用写时复制（COW）等机制，几乎不占额外空间即可保留历史点。

③ 双活 / 多活（Active-Active）

多个数据中心同时对外服务、互为备份。一个中心断电，另一个秒级接管，实现极小 RTO、接近零 RPO。样例中"银行双活数据中心"即典型。

④ 辅助技术

CDP 连续数据保护

记录每一次 I/O，可恢复到任意时间点，RPO≈0。

备份策略

全量 / 增量 / 差异备份的组合。

Failover / Failback

灾难时切到备用中心，恢复后再切回。

4云存储在容灾备份中的应用

云存储（对象存储、云硬盘等）天然带容灾属性，是中小企业实现高等级容灾的低成本路径：

  • 多副本机制：同一份数据存 ≥3 副本，分布在不同可用区（AZ）。单硬件/机柜/机房故障都不丢数据，持久性可达"11 个 9"。
  • 跨地域复制（Cross-Region Replication）：数据自动异步复制到异地 Region，抵御地震、洪水等地域级灾难，对应 L5/L6 级。
  • 快照与镜像：云硬盘快照、整机镜像可一键回滚或拉起新实例，缩短 RTO。
  • 云备份服务：把本地数据备份到云端（混合云备份），无需自建异地机房，按需付费、弹性扩展、免运维。
主区域多副本跨 AZ + 异步跨地域复制 + 快照回滚，三者叠加即成低成本异地容灾方案。

★考试要点小结

两个核心指标必背：RTO＝恢复时间（停多久），RPO＝恢复点/数据丢失量（丢多少），二者都是越小要求越高。
  • 等级标准：认得 国标 GB/T 20988 的 1~6 级，尤其 L5「实时传输·完整设备」、L6「零丢失·远程集群（RPO≈0）」。
  • 关键技术：数据复制（同步/异步）、快照、双活/多活，外加 CDP、全量/增量/差异备份、Failover。
  • 云存储应用：多副本（≥3，跨可用区）、跨地域复制、快照/镜像、云备份服务 → 高可靠（11 个 9）、低成本实现异地容灾。

样题1判断"银行双活数据中心主中心断电、备中心秒级接管" → 对应 极小 RTO、RPO≈0。

样题2判断"云存储多副本+跨区复制保障可靠性" → 正确。
