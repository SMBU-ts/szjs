3.5

典型云平台的选择与比较

一、为什么要“选”——云平台各有基因

核心认识：云计算不是“千篇一律”的，不同平台的“出身”决定了它的强项。AWS 出自电商、Azure 出自企业软件、华为云出自通信设备、百度智能云出自搜索引擎与 AI。同样的需求（如“做一个政务系统”“做一款游戏”“训练一个大模型”）放在不同平台上，在成本、合规、技术匹配度、开发体验上差别很大。

因此考纲要求：①知道常见平台的特点与应用场景；②能针对具体需求选到合适的平台。本考点属于“熟悉”级——要能把平台和对的场景对上号，这是命题重点。

考试重点：不要求背参数，要求建立“平台—强项—场景”的对应关系，并能根据题目给的需求选出最匹配的平台。

二、常见云服务平台全景（特点 + 应用场景）

2.1 国际主流平台熟悉

① AWS（亚马逊云科技 Amazon Web Services）
特点云计算商用先驱（2006 年推 EC2/S3）；全球市场份额第一；服务最全最广；生态最成熟。底层存储架构 Dynamo 采用“最终一致性”哲学——“宁可返回稍旧的数据，也绝不宕机”。
代表服务EC2（计算）、S3（对象存储）、RDS（数据库）、Lambda（Serverless 无服务器）。
应用场景全球化互联网业务、初创公司全栈、企业级应用、跨地域灾备。
② Microsoft Azure（微软云）
特点企业级基因；与 Windows / Office 365 / Active Directory 无缝集成；混合云能力强（本地数据中心与云打通）；IoT 与 AI 整合好。
代表服务Azure VM、Azure IoT Hub、Entra ID（原 AD 身份）、Azure Arc（混合云管理）。
应用场景已使用微软体系的企业、传统行业上云、混合云、工业/政务。
③ Google Cloud（GCP）
特点大数据与 AI/ML 强；Kubernetes 发源地（Borg→K8s），容器原生；开源友好；全球骨干网络质量好。
代表技术GFS（分布式文件系统）、MapReduce（批处理）、BigTable（NoSQL）、Borg；上层 BigQuery、Vertex AI。
应用场景数据密集型业务、容器/微服务原生架构、AI/机器学习训练、技术型互联网公司。

2.2 国内主流平台（重点，考试常考）熟悉

④ 阿里云（Alibaba Cloud）
特点国内市场份额第一；历经“双11”海量并发验证；产品线最全；电商/零售/金融生态强；亚太布局广。
代表服务ECS、OSS（对象存储）、PolarDB、MaxCompute（大数据）。
应用场景电商、零售、中小企业上云、政务、出海（亚太）。
⑤ 腾讯云
特点游戏 / 社交 / 音视频强（直播、点播、实时音视频）；CDN 与网络加速好；微信生态 / 小程序云；性价比突出。
代表服务CVM、COS、云直播、小程序云开发、即时通信 IM。
应用场景游戏、直播、社交、小程序、音视频、在线教育。
⑥ 华为云
特点政务 / 金融 / 制造强；鲲鹏（ARM）算力 + 昇腾 AI 芯片；ModelArts（AI 开发平台）；HCS 混合云；信创自主可控。
代表服务ECS、ModelArts、HCS 混合云、GaussDB。
应用场景政务云、金融云、工业互联网、信创环境、AI 训练。
⑦ 百度智能云
特点AI 基因最强；自研深度学习框架 飞桨 PaddlePaddle；AI 开放平台（语音/视觉/NLP）；Apollo 自动驾驶。
代表服务飞桨、AI 开放平台、Apollo、文心大模型。
应用场景AI 应用、智能客服、工业质检、自动驾驶、大模型。
⑧ 天翼云（中国电信）
特点运营商云；国企/政务背景；网络与 IDC 资源雄厚；“云网融合”；安全合规优势。
代表服务弹性计算、对象存储、专属云、边缘节点。
应用场景政务、国企、医疗、教育、广域边缘节点。
记忆口诀：阿里=电商全；腾讯=游戏音视频；华为=政务金融信创；百度=AI自动驾驶；天翼=运营商国企；AWS=全球全栈；Azure=微软混合；GCP=数据容器。

三、平台对比的七大维度（怎么“比”）

选型时从哪些角度比较
  • ① 成本：计费模式（按量/包年/预留）、单价与性价比。初创和弹性业务看重按需付费。
  • ② 合规与安全：数据本地化、等保合规、信创自主可控要求。政务/金融尤其看重。
  • ③ 技术栈匹配：企业现有生态（如已在用微软 AD/Office → Azure；微信小程序 → 腾讯云）。
  • ④ 生态与服务：第三方市场、技术支持、社区活跃度。
  • ⑤ SLA 与可用性：服务等级协议承诺的可用性（如 99.95%/99.99%）与赔偿。
  • ⑥ 地域覆盖：国内节点 vs 全球节点（出海选 AWS/阿里云国际）。
  • ⑦ 厂商锁定风险：是否依赖专有服务；可考虑多云或基于开源（OpenStack/K8s）降低锁定。
同一套“促销秒杀”系统：用公有云按需扩缩最划算；而银行“核心账务”因合规要求，往往走私有云/混合云（敏感数据私有、前台弹性公有）。

四、需求 → 平台 决策框架（怎么“选”）

按需求直接映射到平台

五步选型流程
  1. 明确需求：业务类型、规模、地域、合规等级。
  2. 定部署模式：公有云 / 私有云 / 混合云 / 社区云（见 1.3 章）。
  3. 匹配平台强项：按上表映射。
  4. 评估成本与 SLA：算总拥有成本、看可用性承诺。
  5. 规避锁定：优先标准接口/开源，必要时多云。
考试重点：题目常给一句需求（如“某市政府要建政务云且要求自主可控”），让你选平台 → 答案指向华为云 / 天翼云；给“游戏公司做直播”→ 腾讯云。

五、考试要点与样题（贴合考纲自编）

必须记牢的对应关系
  • AWS＝全球第一、全栈最全、2006 商用先驱。
  • Azure＝微软生态、混合云强、企业级。
  • GCP＝大数据、AI、K8s 发源地、开源友好。
  • 阿里云＝国内第一、电商/双11 验证。
  • 腾讯云＝游戏、音视频、小程序。
  • 华为云＝政务金融、鲲鹏昇腾、信创、ModelArts。
  • 百度智能云＝AI、飞桨、Apollo 自动驾驶。
  • 天翼云＝运营商、国企政务、云网融合。
易错点：把平台强项“张冠李戴”——例如误以为“政务信创首选腾讯云”（实际华为云/天翼云）；误以为“游戏直播选阿里云”（实际腾讯云更强）。
样题演练（单选 / 多选 / 判断）

【单选】某市政府要建设自主可控的政务云，并需兼顾已有本地数据中心 → 最合适的是：
A. 腾讯云　B. 华为云 / 天翼云（混合云 HCS）　C. GCP　D. 阿里云　答案：B

【单选】一家游戏公司计划上线直播功能，对实时音视频和 CDN 要求高 → 首选：
A. 华为云　B. 腾讯云　C. 天翼云　D. 百度智能云　答案：B

【多选】下列属于国内主流云平台且具“AI 基因”的有：
A. 阿里云　B. 百度智能云（飞桨/Apollo）　C. 华为云（昇腾/ModelArts）　D. 天翼云　答案：BC

【判断】“云计算平台都完全相同，选型只需看价格” → ❌ 错误。不同平台基因与强项不同，需按需求、合规、技术栈综合选择。
