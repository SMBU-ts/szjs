3.3 华为云 · 详细讲解

云计算典型平台（熟悉）｜ 核心技术与服务、各领域的应用场景

考纲要求：熟悉

1华为云概述

定义：华为云（Huawei Cloud）是华为公司推出的云计算服务品牌，提供从 IaaS（基础设施）、 PaaS（平台） 到 SaaS（软件） 的全栈云服务，既包含面向公众的公有云，也包含面向政企的 混合云（HCS）与私有云能力。

在考纲中的位置

华为云属于考纲"第三章 典型平台"中的一节，与以下平台并列考查：

3.1 Google

GFS / MapReduce / BigTable / Borg

3.2 AWS

Dynamo / S3 / EC2 / DynamoDB

3.3 华为云

鲲鹏算力 + 昇腾AI + ModelArts + HCS

3.4 百度云

飞桨 PaddlePaddle / AI 开放平台 / Apollo

3.5 平台选型

按成本、合规、技术栈、生态、SLA 选型

华为云的差异化定位（易混点）

  • 自主软硬件底座：与"纯软件云"不同，华为云有自研芯片（鲲鹏通用算力、昇腾AI 算力）与自研操作系统（欧拉 openEuler），强调自主可控 / 信创。
  • 政企与混合云强项：通过 HCS（Huawei Cloud Stack） 把公有云能力下沉到政企本地机房，满足政务、金融等数据不出域、强合规需求。
  • 云、边、端协同：与鸿蒙（HarmonyOS）、欧拉、5G 协同，适合物联网与工业互联网场景。
考试定位：华为云在考纲中属"熟悉"级别，不要求记忆产品参数，重点是记住它的 四大技术标签（鲲鹏 / 昇腾 / ModelArts / HCS）以及政务、金融、制造三大典型场景。

2华为云的核心技术与服务

华为云的能力可概括为"一颗芯（鲲鹏/昇腾）+ 一个平台（ModelArts）+ 一朵云（HCS 混合云）+ 全套基础云服务"。下面逐项拆解。

① 鲲鹏（Kunpeng）—— 通用算力底座

是什么：华为自研的 ARM 架构服务器芯片（代表：鲲鹏 920），用于通用计算（对标 x86 服务器）， 主打多核、低功耗、自主可控。基于鲲鹏构建的云服务器叫 鲲鹏云服务器（KC1 等）。
  • 价值：在"信创 / 自主可控"背景下，提供不依赖国外 x86 的算力选择。
  • 场景：政务、金融、国企的国产化替代与等保合规。

② 昇腾（Ascend）—— AI 算力底座

是什么：华为自研的 AI 处理器（NPU，达芬奇架构）。训练芯片（如昇腾 910）用于大模型/AI 训练， 推理芯片（如昇腾 310）用于端边云推理，主打高算力、高能效比的 AI 计算。
  • 配套软件栈 CANN 与 AI 框架 昇思 MindSpore，形成"芯片 + 框架 + 平台"的 AI 全栈。
  • 样题示例："政务云用鲲鹏服务器 + 昇腾 AI 做健康码海量并发核验" → 正确。

③ ModelArts —— 一站式 AI 开发平台（PaaS）

是什么：华为云的全流程 AI 开发平台，覆盖数据标注 → 模型训练 → 模型部署 → MLOps 的 AI 开发生命周期， 内置 AutoML、Notebook、分布式训练、模型仓库等能力。
  • 降低 AI 门槛：企业无需自建 GPU 集群即可"开箱即用"地训练与部署模型。
  • 对标：AWS SageMaker、百度 AI 开发平台。

④ HCS（Huawei Cloud Stack）—— 混合云

是什么：把华为公有云的能力"搬"到客户本地数据中心（IDC / 机房）的混合云方案。 用户在自己机房里获得与公有云一致的服务与管理体验，数据物理不出域。
  • 解决痛点：政务、金融对"数据主权 / 合规 / 低时延"的强要求，不能完全上公有云。
  • 本质：公有云技术栈 + 私有化部署，是混合云（Hybrid Cloud）的典型实现。

⑤ 基础云服务（了解即可）

与 AWS/阿里云类似，华为云也提供标准化 IaaS/PaaS 服务，认识名称即可：

类别代表服务作用
计算ECS 弹性云服务器、CCE（云容器引擎 / K8s）虚拟主机、容器编排
存储OBS 对象存储、EVS 云硬盘海量对象存储、块存储
网络VPC 虚拟私有云、EIP 弹性公网 IP隔离网络、公网接入
数据库GaussDB、RDS关系型 / 分布式数据库（信创主力 GaussDB）
OS欧拉 openEuler（服务器）、鸿蒙 HarmonyOS（端/边）云上及边缘操作系统

核心技术速查表（必背）

技术/服务是什么解决的痛点
鲲鹏ARM 架构通用服务器芯片自主可控算力、低功耗多核
昇腾AI 处理器（NPU）高算力 AI 训练与推理

记忆口诀："鲲鹏算、昇腾智、ModelArts 开发易、HCS 把云搬本地"。 考试常把"鲲鹏"与"通用计算"绑定、"昇腾"与"AI"绑定，别搞反。

3华为云在各领域的应用场景

华为云因"自主可控 + 混合云 + 政企服务"的特质，在政务、金融、制造三大领域最为突出（考纲明确列举）。

核心三大场景（必背）

① 政务云
  • 政务系统上云、"一网通办"、城市大脑
  • 健康码 / 疫情防控海量并发核验（鲲鹏 + 昇腾）
  • HCS 混合云保障数据不出域、符合等保
② 金融
  • 核心业务系统上云、分布式核心银行
  • 移动支付风控、智能投顾、反欺诈
  • GaussDB 替代国外数据库（信创）
③ 制造 / 工业
  • 工业互联网平台、设备上云、数字孪生
  • 智能制造、质检 AI（昇腾视觉）、预测性维护
  • 5G + 云 + AI 协同的柔性产线
延伸：医疗 / 教育 / 交通
  • 医疗：影像云存储、基因计算、远程会诊
  • 教育：在线课堂、弹性考试系统、AI 阅卷
  • 交通/能源：车联网、智能电网、矿山/港口

为什么这些领域选华为云？（加分理解）

合规与安全

政企最关心数据主权，HCS 混合云 + 自主软硬件天然契合等保与信创。

端边云协同

鸿蒙 + 欧拉 + 5G，适合物联网、工业互联网等"云边端一体"场景。

AI 全栈

昇腾 + MindSpore + ModelArts，从芯片到平台打通，便于行业 AI 落地。

服务与生态

深耕大 B / 政企客户，懂行业流程，交付与运维体系成熟。

考试重点：应用层只要求"熟悉"——记住 政务、金融、制造 三个关键词及其代表性用法即可； 能区分"华为云擅长政企/混合云"与"AWS 擅长全球公有云 / 百度云擅长 AI 与自动驾驶"的差异。

  • 样题：政务云用鲲鹏+昇腾做健康码并发核验 → 正确；华为云差异化＝自主可控 + 混合云 + 政企服务。
