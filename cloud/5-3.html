5.3绿色节能技术

5.3 绿色节能技术 · 详细讲解

云计算数据中心（重点 · 掌握）｜ 能耗指标、配电与空调节能、典型绿色数据中心

考纲要求：掌握

1为什么需要绿色节能技术

背景：数据中心是云计算的"能耗大户"。一台数据中心的总能耗中，IT 设备（服务器、网络、存储）只约占一半， 另一半消耗在供电、制冷等配套系统上。绿色节能技术的目标，就是让更多电能真正用在计算上，减少浪费、降低 PUE。

核心指标：PUE（电能使用效率，Power Usage Effectiveness）

PUE = 数据中心总能耗 ÷ IT 设备能耗
  • PUE ≥ 1，理论上越接近 1 越节能（意味着配套系统几乎不耗电）。
  • 早期传统机房 PUE 约 2.0（一半电被配套系统吃掉）；
  • 现代绿色数据中心可做到 1.2 甚至 1.1 以下（如 Google、阿里张北）。
  • 与之相关的还有 DCiE = 1 / PUE（数据中心基础设施效率），数值越大越好。
易考概念：PUE 衡量的是"基础设施能效"，它不直接衡量 IT 设备本身的计算效率， 但能直观反映空调、配电等配套系统的节能水平——这正是 5.3 节的主角。

绿色数据中心的定义

在保证信息系统安全、稳定、高效运行的前提下，通过节能、减排、可再生能源利用、资源复用等手段， 在整个生命周期（规划、设计、建设、运维、报废）内实现最小环境 footprint 的数据中心。

节能

配电、空调、IT 设备全面降耗。

节地

高密度部署、模块化、紧凑布局。

节水

自然冷却减少冷却水消耗。

环保

可再生能源、余热回收、绿色材料。

2配电系统节能技术

配电系统是数据中心的"血管"。电能从市电进入后，要经过多级转换才能到达服务器，每一次转换都有损耗。 配电节能的核心是：减少转换环节、提高转换效率、按需供电。

① 减少转换环节：市电直供 / 高压直流（HVDC）

技术做法节能原理
高压直流供电
(HVDC)		 用 240V/336V 高压直流替代传统交流 UPS，服务器电源内部再做一次 DC-DC 转换 省去"交流→直流→交流"多次逆变；
减少转换级数，效率提升至 94%~97%
市电直供 优质市电区域让 IT 设备直接由市电供电，仅在末端加小容量电池保障 省掉 UPS 整段损耗；适合电网稳定场景
去掉"AC/DC 双重转换" 传统路径：市电 AC→UPS(AC/DC/AC)→PDU→服务器电源(DC/AC/DC)，环节多 每多一级转换约损耗 3%~5%，合并后可显著降低

② 提高转换效率：模块化 / 高频 UPS

  • 模块化 UPS：随负载增长"按需扩容"，避免大机器长期低载运行（低载时效率骤降）。
  • 高频机替代工频机：去掉笨重变压器，体积更小、效率更高（可达 95%+）。
  • ECO 模式（节能模式 / 旁路模式）：电网正常时让电流走旁路，效率接近 99%，仅在异常时切换逆变。

③ 智能配电与能耗监测

  • 智能 PDU / 母线槽：实时监测每条支路电流、功率，发现"僵尸负载"（低利用率高耗电）。
  • 动态无功补偿：提高功率因数（接近 1），减少线路无功损耗。
  • 就近供电：变压器、UPS 靠近机柜，缩短供电路径、降低线损。
记忆口诀：配电节能 = 少转换（HVDC/市电直供）＋ 高效率（模块化/高频/ECO）＋ 会监测（智能 PDU）

3空调系统节能技术

制冷是数据中心第二大耗电户（往往占总能耗 30%~40%）。空调节能有两句话："能借自然风就别开压缩机"， "冷风热风别打架"。

① 自然冷却（Free Cooling）—— 节能之王

当室外温度足够低时，直接用自然环境为机房降温，压缩机少开或不开。

方式原理适用
风侧自然冷
(新风/空气 économiser)		 引入低温室外新风直接冷却，过滤后送入机房 寒冷/干燥地区；需空气处理
水侧自然冷
(冷却塔/干冷器)		 低温室外空气冷却循环水，再通过板换给机房降温 北方/过渡季长地区
间接蒸发冷却 利用水蒸发吸热 + 空气换热，机房内外空气不混合 干旱炎热地区（如华为、AWS 常用）
考点："自然冷却小时数 / 自然冷源利用率"越高，PUE 越低。我国北方（张北、贵安、内蒙古）建大型数据中心， 正是为了吃自然冷源红利。

② 气流组织优化：冷热通道隔离

  • 冷热通道封闭：机柜"面对面、背对背"排列，冷风从正面送、热风从背面回，封闭冷/热通道防止冷热混合。
  • 下送风 + 穿孔地板：冷风从架空地板下送出，精准到达机柜进风面。
  • 封闭通道（Containment）：把冷通道或热通道用顶盖/隔帘封起来，回风温度更高、冷机效率更好。

③ 近端制冷：行级空调 / 背板热交换

  • 行级（列间）空调：空调紧挨机柜列，缩短送风距离，制冷更精准。
  • 背板热交换器：在机柜背面装换热盘管，就近把热风"压"回冷风。
  • 相比传统"房间级大空调"，近端制冷可显著降低风机功耗与冷量损耗。

④ 液冷技术（高密场景的终极方案）

类型做法特点
冷板式液冷金属冷板贴住 CPU/GPU，管路循环冷却液带走热量改造小、成熟，单机柜可 20~50kW
浸没式液冷服务器整板浸没在绝缘冷却液中（阿里"麒麟"采用）PUE 可逼近 1.1，散热效率极高
喷淋式液冷冷却液直接喷淋到发热元件适合超高密度机柜

⑤ 运行参数与设备优化

  • 放宽温湿度设定：按 ASHRAE 建议，进风温度提高到 18~27℃（甚至更高允许上限），减少制冷负荷。
  • 变频技术：变频压缩机 + EC 高效风机，按需调节转速，避免定频"满负荷硬扛"。
  • 提高冷冻水温：提高冷凝器出水温度，让冷机能效比（COP）上升。
记忆口诀：空调节能 = 自然冷（free cooling）＋ 隔冷热（通道封闭）＋ 就近冷（行级/背板）＋ 上液冷（浸没）＋ 调参数（升温度/变频）

4其他配套节能技术

IT 设备节能

虚拟化提高利用率、高能效服务器、CPU 动态调频（DVFS）、闲置部件休眠。

可再生能源

风电、光伏、水电直供，购买绿电/绿证，从源头降碳。

余热回收

回收服务器废热用于周边供暖（如腾讯天津数据中心供热）。

智能运维 DCIM

AI 调优冷却策略、容量预测、3D 热力图定位热点。

关键认识：IT 设备利用率本身也是"绿色"核心——虚拟化（见 2.1）让一台服务器干三台的活， 等于少买设备、少耗电、少制冷，是绿色节能的"源头活水"。

考法二：问"液冷代表？"→ 答：阿里浸没式液冷；问"AI 调优冷却代表？"→ Google。

6考试要点速记

  1. PUE 公式：总能耗 ÷ IT 设备能耗；越接近 1 越好；传统 ~2.0，绿色可 ≤1.2。
  2. 配电节能：HVDC 高压直流、市电直供、模块化/高频 UPS、ECO 模式、智能 PDU——核心是少转换、高效率。
  3. 空调节能：自然冷却（风侧/水侧/间接蒸发）、冷热通道隔离、行级/背板近端制冷、液冷（冷板/浸没）、升温度+变频。
  4. 源头节能：虚拟化提高 IT 利用率，是绿色节能的基础。
  5. 典型数据中心：Google（AI 控冷）、阿里（浸没液冷）、微软（海底/海水）、腾讯（余热回收）、华为（间接蒸发+模块化）。
  6. 选址逻辑：利用自然冷源 → 高纬寒冷/干旱地区；利用绿电 → 风电光伏富集区。
一句话总结：绿色节能 = 配电少损耗 + 空调借自然 + IT 高利用 + 能源可再生的系统工程。
