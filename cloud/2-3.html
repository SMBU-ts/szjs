2.3 软件定义网络和网络功能虚拟化 · 详细讲解

云计算 / 网络关键技术（重点 · 掌握）｜ SDN · NFV · 应用场景 · VPC 与网络隔离

考纲要求：掌握

1SDN（软件定义网络）的概念

定义：SDN（Software-Defined Networking，软件定义网络）是一种网络架构理念—— 将传统网络设备中控制平面（Control Plane）与数据平面（Data Plane / 转发平面）解耦， 把分散在各设备上的"控制大脑"抽离出来，集中到统一的 SDN 控制器上，并通过开放、可编程的接口 实现对全网转发行为的集中控制与灵活调度。

为什么需要 SDN？（传统网络的痛点）

  • 控制与转发紧耦合：每台交换机/路由器"自己算路由、自己转发"，网络越大越难统一管理。
  • 配置竖井、难以灵活：新业务上线需逐台登录设备改配置，慢且易错。
  • 硬件封闭：功能固化在厂商设备里，创新受限于厂商。

三大核心特征（必背）

① 转控分离

控制逻辑上收到控制器，转发设备只负责"按表转发"，变成哑交换机/白盒。

② 集中控制

控制器掌握全网拓扑与状态，逻辑上集中，全网视图统一，策略一次下发。

③ 开放可编程

通过开放接口（南向/北向）编程控制网络，业务可动态调整流量，无需改硬件。

典型三层架构

应用层
(Application)

网络应用 / 业务 APP

如流量工程、负载均衡、安全策略、网络监控。通过北向接口调用控制器能力（常见 REST API）。

↑ 北向接口（开放 API，如 REST） ↓
控制层
(Control)

SDN 控制器（大脑）

全网"中枢"：维护拓扑、计算转发路径、生成流表、下发策略。代表：OpenDaylight、ONOS、Floodlight。

↑ 南向接口（控制-转发通信，如 OpenFlow） ↓
基础设施层
(Infrastructure)

转发设备（交换机/路由器）

只做数据转发，按控制器下发的流表（Flow Table）匹配转发，本身不含复杂控制逻辑。

两个关键接口： 南向接口——控制器↔转发设备之间，最典型是 OpenFlow（标准化流表下发协议）； 北向接口——控制器↔上层应用之间，多为 REST API（非强制标准，强调开放可编程）。
易混点：SDN 是架构思想，不绑定具体协议；OpenFlow 只是南向接口的一个实现协议。 记住一句话："控制与转发分离 + 集中控制 + 开放接口" 就是 SDN 的本质。

2NFV（网络功能虚拟化）的概念

定义：NFV（Network Functions Virtualization，网络功能虚拟化）是一种实现方式—— 利用标准 IT 虚拟化技术，将传统依赖专用硬件设备的网络功能 （如防火墙、负载均衡、路由器、入侵检测 DPI、NAT 等），以软件形式（VNF） 运行在通用 x86 服务器 / 云基础设施上，从而摆脱对昂贵专用网元（middlebox）的依赖。

核心名词

VNF

Virtual Network Function，虚拟网络功能——跑在通用硬件上的"软件版"网络设备（如虚拟防火墙）。

NFVI

NFV Infrastructure，NFV 基础设施——通用服务器+存储+网络硬件，加上虚拟化层（Hypervisor）。

MANO

Management & Orchestration，管理编排——含 VIM、VNFM、NFVO，负责资源编排与生命周期管理。

NFV 参考架构（三要素）

组成作用对应类比
NFVI
基础设施层		提供计算/存储/网络资源池，底层是通用硬件+虚拟化层（如 KVM）云的"资源池"（类比 IaaS 底座）
VNF
虚拟网络功能		各种以软件实现的网络功能（vFW、vLB、vRouter 等）跑��云上的"网络应用"
MANO
管理与编排		VIM（基础设施管理）、VNFM（VNF 生命周期）、NFVO（跨域编排与资源调度）"运维大脑"，替代手工配置专用设备

NFV 的价值

  • 降成本：减少专用硬件采购，降低 CAPEX（建设）与 OPEX（运维）开销。
  • 快上线：新网络功能"软件安装即部署"，业务上线从月级降到小时/分钟级。
  • 弹性伸缩：按负载动态扩缩 VNF 实例，资源利用更高。
  • 避免厂商锁定：功能跑在通用硬件上，可多厂商混部。
考试重点：SDN 与 NFV 是互补而非替代的关系—— SDN 解决"网络流量怎么被控制/转发"（控制平面重构）； NFV 解决"网络功能跑在哪"（用通用硬件替代专用设备）。 两者结合：用 NFV 把网络功能虚拟化、用 SDN 灵活调度这些功能的流量，这就是现代云/5G 网络的核心思路。

3SDN 的典型应用场景

SDN 的"集中控制 + 灵活编程"特别适合规模大、变化快、需统一调度的网络环境。典型场景如下：

① 数据中心网络（DCN）

大二层组网、东西向流量调度、网络自动化。最经典场景：VM/容器迁移后网络策略跟随，无需手工改配置。

② SD-WAN（软件定义广域网）

把 SDN 思想用到企业广域网：智能选路、叠加多条链路（互联网+专线）、降低专线成本、集中策略管控。

③ 园区网 / 校园网

全校/全园区统一策略下发、按身份（账号/角色）自动化授权，简化海量接入设备管理。

④ 网络安全与流量引流

集中把可疑流量"引流"到安全设备（防火墙/IDS）清洗，再回注；实现微分段与统一安全策略。

⑤ 5G 与网络切片

5G 核心网（SBA 服务化架构）依赖 SDN/NFV 实现网络切片：一张物理网切出多张逻辑专网（eMBB/URLLC/mMTC）。

⑥ 云数据中心 / 多租户

为不同租户提供隔离、可编程的虚拟网络（即下方 VPC 的底层支撑），弹性伸缩。

场景归纳（答题用）

  • 本质诉求：网络需要"灵活、自动、可编程、统一管控"时，就适合 SDN。
  • 高频考点场景：数据中心 SD-WAN 园区网 5G网络切片 云多租户 安全引流。
一句话答题模板："SDN 适用于需要集中管控、弹性调度、业务快速上线的网络场景，典型如数据中心、SD-WAN、5G 网络切片与云多租户网络。"

4VPC（虚拟私有云）与网络隔离技术

4.1 VPC 是什么

定义：VPC（Virtual Private Cloud，虚拟私有云）是公有云为用户提供的逻辑隔离的私有网络空间。 用户可自定义 IP 网段、子网、路由表、网关与安全策略，相当于在公有云里"圈出一块专属数据中心"， 与其他租户在逻辑上彼此隔离、互不可见。

VPC 的核心组成

私有网段

用户自定义 CIDR（如 10.0.0.0/16），来自 RFC1918 私有地址空间。

子网 Subnet

VPC 内按可用区划分的 IP 地址段，是资源（云主机）落位的单位。

路由表 Route Table

控制子网内流量的去向（去公网/去其他子网/去专线）。

网关 Gateway

互联网网关、NAT 网关、VPN 网关、对等连接等出入口。

安全组 Security Group

实例级、有状态的虚拟防火墙（默认拒绝入、允许回包）。

网络 ACL（NACL）

子网级、无状态的防火墙（需分别配置入/出规则）。

4.2 网络隔离技术（重点）

VPC 能实现"租户间彼此看不见"，靠的是下面这些隔离技术——从二层到三层、从硬件到软件层层设防：

技术隔离层级核心原理特点 / 局限
VLAN
虚拟局域网		 二层（数据链路层）
基于 802.1Q 标签		 给数据帧打 Tag，划分不同广播域 实现简单；但数量上限 4096、跨数据中心大二层困难、隔离粒度粗
VXLAN
虚拟扩展局域网		 Overlay（二层
封装在三层之上）		 用 24 位 VNI 在 IP 网络上再叠加一层逻辑二层网络 支持1600 万+ 租户、可跨数据中心大二层；云多租户主流方案
子网划分 三层（网络层） 用私有网段（10/8、172.16/12、192.168/16）做 IP 隔离 配合路由表控制互通，是 VPC 的基础
安全组 实例级（虚拟防火墙） 有状态规则，控制实例的入/出流量 默认拒绝、跟踪连接状态；云主机防护首选
网络 ACL 子网级（虚拟防火墙） 无状态规则，分别定义入/出方向 作为子网边界的额外防线，规则按顺序匹配
VPN / 专线 连通与边界 IPsec VPN / 物理专线把本地 IDC 安全接入 VPC 打通本地与云，且全程加密 / 独享，保障传输隔离
微隔离
Micro-segmentation		 工作负载级 基于身份/标签对单个工作负载做细粒度访问控制 东西向流量防御，防止"一点突破、全网横向移动"
VLAN vs VXLAN（常考对比）：VLAN 是传统二层隔离，标签 12 位（4096 个）、难跨数据中心； VXLAN 是Overlay 大二层，VNI 24 位（1600 万+个）、可跨三层网络构建大二层， 是云多租户隔离的基石。一句话：VLAN 数量不够、跨域不行 → VXLAN 来补。

4.3 VPC 与 SDN/NFV 的关系

  • VPC 是网络虚拟化的"落地产品"：用户在云控制台点几下就能拥有隔离网络，底层的逻辑网络靠 SDN + Overlay（VXLAN）实现。
  • SDN 提供"集中控制网络"：VPC 的路由、ACL、引流都由控制器统一下发。
  • NFV 提供"虚拟网络功能"：VPC 内的 NAT 网关、VPN 网关、防火墙常以 VNF 形式跑在通用硬件上。
小结：SDN 管"怎么转发"、NFV 管"功能跑哪"、VPC 是"给用户看的隔离网络空间"—— 三者共同构成云网络的底座。VPC 的本质就是基于 Overlay/SDN 的多租户网络隔离。

★考试速记清单

  • SDN＝控制平面与数据平面分离 + 集中控制 + 开放可编程；三层＝应用层/控制层/基础设施层； 南向接口（OpenFlow）连设备，北向接口（REST API）连应用。
  • NFV＝把防火墙/负载均衡等网络功能从专用硬件搬到了通用服务器（软件 VNF）上； 三要素：NFVI（底座）+ VNF（功能）+ MANO（编排）。
  • SDN ≠ NFV：SDN 管"转发控制"，NFV 管"功能承载"，互补关系。
  • SDN 场景：数据中心、SD-WAN、园区网、5G 网络切片、云多租户、安全引流。
  • VPC＝云上逻辑隔离的私有网络，可自定义网段/子网/路由/网关；靠VXLAN（Overlay）+ 安全组 + NACL 隔离。
  • VLAN vs VXLAN：VLAN 12 位（4096）、二层、难跨域；VXLAN 24 位 VNI（1600 万+）、Overlay 大二层、云多租户主流。
  • 安全组（有状态 / 实例级） vs 网络 ACL（无状态 / 子网级）——常考辨析。
